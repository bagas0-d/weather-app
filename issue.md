# Project: Weather App Scaffolding

## Project Overview

- Buat project baru di folder ini menggunakan Vite + React + TypeScript.
- Sertakan asset, desain, dan style guide yang sudah ada di repositori.
- Siapkan fondasi project siap diimplementasikan.

## Technology Stack

- **Framework**: Vite + React + TypeScript
- **UI**: shadcn/ui
- **Styling**: Tailwind CSS
- **Data Fetching**: TanStack Query
- **Form**: React Hook Form
- **State**: Zustand
- **Linting**: ESLint

## Setup Scope

- Inisialisasi project Vite + React + TypeScript.
- Install dan konfigurasi library: shadcn/ui, Tailwind CSS, TanStack Query, React Hook Form, Zustand, ESLint.
- Integrasi asset, desain, dan style guide yang sudah ada.
- Buat struktur folder awal project.
- Buat entry point dan placeholder application.
- Siapkan file konfigurasi dasar (Tailwind, shadcn, TS config, dll).
- Buat README berisi instruksi instalasi dan menjalankan project.

## Expected Deliverables

- Project folder dengan semua file konfigurasi dan skaffold.
- README singkat dengan instruksi install dan run.
- Folder sumber yang sudah siap diimplementasikan fitur Weather Forecast.
- Asset dan desain sudah tersedia di project.
